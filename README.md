# ECN-BENCH: retrospective extraction audit

Publication package **1.2.2**, updated 2026-09-08. Start with
[freeze review](00_docs/FREEZE_REVIEW.md) and
[GitHub publishing instructions](00_docs/GITHUB_PUBLISH.md).
This folder contains the paper, offline analysis inputs, historical code and
audit trail. Raw traces are a separate companion ZIP, described in
[the trace manifest](03_traces/TRACE_MANIFEST.json); they are not required to
reproduce the current numerical results. The GitHub repository is uploaded but
private; no public deposition has been made.

This package accompanies **ECN-BENCH: Design, Systems Engineering, and a Forensic Audit of Multi-Agent Forecasting — Full Technical Report** (restored full edition: 2026-09-06).

The central observation is extraction-configuration sensitivity: on 132 matched simulated evidence records, near-uniform counts change from 31 under Evaluator J to one under Evaluator A. This does not establish which reading faithfully represents the discussion or why the configurations differ.

Four campaigns cover 30 events and three recorded conditions. Condition A is a shared reference, not a separate per-model baseline. B uses nominally relevant injections, including documented wrong-topic inputs; C uses an unrelated repeated administrative message. The injection bank is not length-matched.

## Current results

Use `08_paper/ecn_bench_paper.pdf` for the full report. It restores the rubric, protocol, engineering, scaling and audit context; regenerates all-event lookup tables; and preserves all 30 earlier figures in an explicitly historical register. Current estimates come from `paper_results.json` and `paper_full_results.json`, generated by `05_analysis/scripts/paper_analysis.py` and `paper_full_analysis.py`. `ecn_bench_paper_short.pdf` is a separate abridged version, and the conference wrapper renders that short version, not the full report.

The extended audit finds Qwen2.5-14B T1 still asks a different question despite matching options and outcome. The full tables retain all 30 IDs, but aligned aggregate comparisons exclude T1 across campaigns (29 events). The main 20-event analysis never includes T1 and is unchanged. No additional simulation was run.

The post-release 20-event subset is **not contamination-clean**: evaluator knowledge and retrospective inputs remain uncontrolled. Forecasting and single-agent comparisons are exploratory. All pooled uncertainty retains repeated campaigns within event clusters. See `00_docs/PROVENANCE.md`.

## Reanalyse without model calls

From this directory:

```bash
python -m pip install -r 05_analysis/requirements-analysis.txt
python tools/verify_release.py
python 05_analysis/scripts/paper_analysis.py --data-root . --output-dir 08_paper
python 05_analysis/scripts/paper_full_analysis.py --data-root . --output-dir 08_paper
tectonic --only-cached --keep-logs 08_paper/ecn_bench_paper.tex
```

No simulation, model download, credentials or API calls are needed for the analysis. The TeX command requires a populated local package cache; see `00_docs/REPRODUCE.md`.
