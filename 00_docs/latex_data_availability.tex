\section*{Data Availability}
The replication package accompanies this manuscript and supports offline
reanalysis of the frozen observations. It is hosted in the private GitHub
repository \url{https://github.com/MinhHixn/ECN-BENCH}; access requires owner
authorization. The principal branch is \texttt{main}. Tag \texttt{v1.2.1}
identifies the initially uploaded freeze, and the authorship/repository metadata
revision is package version \texttt{1.2.2}. No DOI has been assigned. See the
package's reproduction instructions and provenance for missing traces and limits
on replaying the historical evaluator deployment.
